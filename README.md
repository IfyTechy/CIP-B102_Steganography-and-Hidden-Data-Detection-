# Practical Lab 4 — Steganography and Hidden Data Detection

## Course
**Course:** SBT-DF202 — Computer and Digital Forensics  
**Institution:** International Cybersecurity & Digital Forensics Academy (ICDFA)

## Overview
This repository contains the forensic evidence, analysis, and final documentation for Practical Lab 4. The assessment covers steganographic payload embedding, least-significant-bit (LSB) detection, hash verification, and passphrase recovery.
